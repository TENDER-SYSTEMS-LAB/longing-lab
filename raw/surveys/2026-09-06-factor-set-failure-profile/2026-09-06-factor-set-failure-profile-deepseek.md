LONGING — Factor Set Failure Profile Review
Round 3: Failure Profiles
Section 1 — Failure Profile, One per Set
SET A — 8 Factors
(a) Mispricing

Handwritten Letter — overvalued. Friction Premium (Factor 6) and Physical Grounding (Factor 8) move together on this security, creating a compounded positive effect that is larger than either factor individually justifies. The letter's price is bid up as if both inconvenience and physicality are independent sources of value, when in practice they are the same underlying preference expressed twice.

Aimless Walking — undervalued. The set lacks a factor for ambient or unproductive time use. Attention Scarcity (Factor 5) frames walking as a competitor for scarce cognitive resources rather than as a release from them. Physical Grounding (Factor 8) captures the spatial dimension but not the temporal one. The walk is priced as if it loses to digital alternatives, when its value may lie precisely in being non-productive.

Film Photography — risk of mispricing in both directions. Variance Elimination (Factor 3) penalizes it for retaining chance, while Performative Legibility (Factor 7) rewards it as a signal. The net price depends entirely on which factor is currently weighted more heavily, making the security extremely volatile without corresponding fundamental change.

(b) Unattributable events

Event: A widely publicized study finds that people who receive handwritten letters report higher relationship satisfaction than those who receive emails, but the effect is entirely driven by recipients over 60.

Where it lands: Splits across Synthetic Substitution (Factor 1 — but the letter wasn't substituted), Temporal Compression (Factor 2 — but delay was already present), Friction Premium (Factor 6 — but the effect isn't cyclical or market-driven), and Physical Grounding (Factor 8 — but it's about the recipient's age, not the physical medium). The set cannot attribute the generational specificity.

Event: A new social media platform, deliberately slow and asynchronous, gains rapid adoption among teenagers. It has no algorithmic feed, no read receipts, and no typing indicators.

Where it lands: Temporal Compression (Factor 2) would move against this event, but the event is a success. Variance Elimination (Factor 3) would also move against it. Attention Scarcity (Factor 5) is ambiguous — the platform is low-attention but also competes with high-attention apps. The set has no factor for preferences counter to its own directional assumptions. The event would require a residual explanation.

(c) Identification failure at eleven securities

Factors 1 and 2 collapse. Synthetic Substitution and Temporal Compression are distinguishable on a conceptual level but across these eleven securities, their loading vectors are nearly identical. Every security affected by substitution is also affected by compression, in the same direction. Handwritten Letter is penalized by both; Film Photography is penalized by both; Unplanned Visit is penalized by both. No security is exposed to one but not the other. The factors separate conceptually but not empirically.

Factors 6 and 7 have partial collapse. Friction Premium and Performative Legibility both reward Handmade Object, Film Photography, and Physical Media, and both penalize Unplanned Phone Call (convenient but low-status). They separate only on Solitude, where Friction Premium is neutral but Performative Legibility is negative. This is one security's worth of separation — inadequate for stable identification.

(d) Double counting

The act of choosing a difficult practice enters twice. A person who writes a handwritten letter incurs friction (Factor 6), which is priced positively. That same decision also signals something about their social capital (Factor 7), which is also priced. Both factors capture the same behavioral choice. The security is rewarded once for doing something inconvenient, and again for being seen as the kind of person who does inconvenient things. The real-world cause is singular; the ledger counts it twice.

(e) What this set can never say

That the value of a practice might be intrinsic, not relative to a digital substitute. Every factor in SET A defines value in opposition to something else: substitution, compression, elimination, atomization, scarcity. The set has no language for "this practice is valuable because of what it is," only for "this practice is valuable because it resists what is replacing it." If a practice is not threatened, or if its value is independent of threat, SET A cannot express that.

(f) Falsification risk

"Film photography must be able to revive" — at risk. Under SET A, Film Photography is caught between Variance Elimination (penalizing its chance element) and Performative Legibility (rewarding its signal value). For a revival to occur, Performative Legibility must dominate strongly enough to overcome the structural decay factors. This is possible but the set makes it difficult — the structural factors are secular and slow-moving, while the positive factor is cyclical and mean-reverting. The revival would need to be driven almost entirely by social signaling, not by any fundamental revaluation of the practice itself.

"Attribution must sum exactly" — passes. The set has no residual in its design.

"Model must sometimes contradict the artist" — passes. The artist's bias toward the human is not structurally enforced.

SET B — 12 Factors (10 Priced)
(a) Mispricing

Waiting for a Reply — undervalued. Latency Collapse (F1) treats waiting as a cost to be eliminated. Functional Substitution (F2) treats it as inefficient. The set has no positive valuation for anticipation, suspension, or the state of not-yet-knowing. The security is priced solely as a deprivation, never as an experience.

Serendipitous Discovery — overvalued by Predictive Pre-selection (F3) and undervalued by Attention Slack (F6), netting to a price that is unstable and likely wrong in either direction. The model treats serendipity as the absence of prediction rather than as a positive outcome of environmental structure. The price oscillates with the weights on F3 and F6, neither of which properly captures the phenomenon.

Solitude — priced incorrectly because F4 (Coordination Formalization) and F9 (Generalized Trust) are unpriceably zero. Solitude is the only security whose value is directly affected by these factors: high coordination formalization makes solitude more necessary (positive effect); high trust makes solitude less necessary (negative effect). With both factors zero, Solitude's price is missing two important drivers. The security is effectively unmodeled in its social dimension.

(b) Unattributable events

Event: A viral essay argues that the expectation of immediate replies is causing widespread anxiety, and people begin deliberately delaying responses as a form of self-care.

Where it lands: Latency Collapse (F1) would move toward faster replies, but this is a reversal. Coordination Formalization (F4) is unpriced. Attention Slack (F6) might move in either direction. The event is a cultural counter-movement to the set's structural assumptions, and no factor cleanly captures a voluntary deceleration. The move would split across residuals and status effects.

Event: A major photography retailer announces it will stop selling film cameras entirely; simultaneously, a new film development startup raises significant venture funding.

Where it lands: The first half moves Dematerialization (F5) — physical carrier substitution. The second half moves Status Coding (F12) positively — the practice is now elite/scarce. But these are opposite moves on the same security, driven by different factors, and the set cannot tell whether the net effect is structural decline or cyclical revaluation. The two events are conflated.

(c) Identification failure at eleven securities

F1 (Latency Collapse) and F5 (Dematerialization) collapse. Across these eleven securities, latency reduction and dematerialization are perfectly correlated. Every practice that can be dematerialized is also subject to latency reduction; every practice that cannot be dematerialized is also latency-resistant. No security separates them.

F6 (Attention Slack) and F10 (Commodification/Enclosure) are near-collapsed. Both factors reduce the value of practices that require sustained attention (Attention Slack falls, making attention scarce; Commodification rises, making practices monetized and thus less pure). They move in opposite directions but on the same securities, creating a difference-of-two-curves identification problem.

F11 (Friction Premium) and F12 (Status Coding) partially collapse. Both are cyclical valuation factors that reward inconvenience and punish convenience. They separate only on Physical Media (which F11 rewards for effort but F12 penalizes as obsolete) — insufficient separation.

(d) Double counting

The choice to engage in a practice is counted through both Block II conditions and Block III valuation. A decline in Generalized Trust (F9) reduces the security's fundamental value through Block II. The same decline raises Friction Premium (F11) because people value trustworthy interaction more. The same real-world event enters the ledger twice: once as a condition change, once as a valuation shift.

Status Coding (F12) and Commodification (F10) double-count social value. A practice that becomes commodified loses status; a practice that loses status becomes more likely to be commodified. The set tracks both directions separately, but in practice they are the same process observed from different ends.

(e) What this set can never say

That a practice might be valuable precisely because it is inefficient. The set treats efficiency as a baseline — latency is "collapse," substitution is "functional," coordination is "formalization." Everything is measured against a world of maximum efficiency. The possibility that a practice's value is positively related to its inefficiency (that waiting is not a cost to be eliminated but a benefit to be preserved) is structurally unsayable. The word "friction" in F11 is the closest approximation, but it treats inefficiency as a premium that can be bid up or down, not as an inherent good.

(f) Falsification risk

"Attribution must sum exactly" — passes. F4 and F9 contribute zero; the remaining ten sum exactly.

"Film photography must be able to revive" — passes, but with a caveat. The revival would have to come through Status Coding (F12) and Friction Premium (F11), both cyclical. The set's structural factors (F1-F5) are secularly negative. A revival is possible but requires the cyclical factors to override structural decline — possible but precarious.

"Model must sometimes contradict the artist" — passes. The artist's bias is not structurally enforced.

"Collinearity must stay bounded" — at risk. The collapse of F1/F5 and near-collapse of F6/F10 suggests the set is underidentified. Attribution can sum exactly while being meaningless if factors are interchangeable.

SET C — 5 Factors
(a) Mispricing

Film Photography — severely overvalued. The set has only one positive factor (SR — Social Revaluation) and four negative factors. Film Photography is the most exposed security to SR, but its price is almost entirely dependent on this single factor moving against the structural headwinds of FE (Friction Elimination), AD (Agency Displacement), and MD (Material Decoupling). The security is priced as if social status can fully compensate for structural obsolescence, which overstates its resilience.

Aimless Walking — undervalued. AS (Attention Scarcity) treats walking as competing for attention, rather than as a means of replenishing it. No factor captures non-productive, non-attentional time. The security's value is zero from Attention Scarcity's perspective, which underweights its restorative function.

Unplanned Visit — mispriced due to factor compression. FE (Friction Elimination) penalizes unplanned visits (friction), but SR (Social Revaluation) might reward them (authenticity). The net price is determined by the balance between two factors that are both poorly specified for this security. The visit is not a coherent exposure.

(b) Unattributable events

Event: A new law mandates that all customer service interactions must offer a human option alongside automated systems, and usage of the human option increases.

Where it lands: FE (Friction Elimination) would move slightly negative (more friction reintroduced). AD (Agency Displacement) would move positive (human agency is being preserved). But these are opposite directions on the same real-world change. The set cannot decide whether the event is bad (more friction) or good (more human agency). It would split the move.

Event: A generation of young people begins collecting vinyl records not for status, but because they find the physical ritual calming.

Where it lands: SR (Social Revaluation) — but this is a functional, not a status, explanation. MD (Material Decoupling) — but this is about re-embodiment, not decoupling. AS (Attention Scarcity) — but the ritual is attention-consuming, not attention-conserving. The event is a demand for physicality for intrinsic, not signaling, reasons. No factor fits.

(c) Identification failure at eleven securities

All five factors are at risk of collapse. With only five factors across eleven securities, the factor space is dramatically underdimensioned. The specific collapse pairs:

FE (Friction Elimination) and MD (Material Decoupling) are nearly identical in their loadings. Every security affected by friction is also affected by material decoupling, in the same direction. Handwritten Letter, Film Photography, Physical Media, Handmade Object — all are penalized by both.

AD (Agency Displacement) and MD (Material Decoupling) are functionally equivalent for most securities. A practice that is materially decoupled is almost always also agency-displaced; a practice that is agency-displaced is almost always materially decoupled.

SR (Social Revaluation) and AS (Attention Scarcity) operate on the same securities in opposite directions, creating a difference-of-two-factors identification problem. They are identifiable only if their weights are constrained, but with eleven securities and no cross-sectional variation, the constraints are arbitrary.

The set is effectively a one- or two-factor model masquerading as five factors.

(d) Double counting

The removal of friction is counted twice. FE (Friction Elimination) removes friction directly. MD (Material Decoupling) removes friction indirectly by removing the physical carrier. A practice that becomes dematerialized is also friction-reduced. The same real-world process enters twice.

Social status enters twice. SR (Social Revaluation) is explicitly about status. But AS (Attention Scarcity) also captures status indirectly — practices that are attention-demanding are often also high-status. The same social signaling process is split across two factors.

(e) What this set can never say

That value might increase with friction, materiality, and agency all at once. The set has one positive factor (SR) and four negative factors. It is structurally biased toward decline. A practice that is high-friction, high-materiality, high-agency, and high-attention all at once is penalized by every factor except SR. The set cannot express the possibility that these attributes are complementary sources of value, not independent costs to be netted.

(f) Falsification risk

"Attribution must sum exactly" — passes, but trivially. With only five factors, the residual is small, but this is because the factor space is under-specified, not because the model is well-identified.

"Film photography must be able to revive" — at severe risk. Film Photography is penalized by FE (friction), AD (agency displacement), MD (material decoupling), and AS (attention scarcity). It is rewarded only by SR (social revaluation). For a revival, SR must dominate all four structural factors simultaneously — a heroic assumption. The security can only revive if social status entirely overrides structural reality, which is unlikely and imposes a fragility on the model.

"Model must sometimes contradict the artist" — passes, but the artist's bias is already structurally embedded. The model is so negative on everything that it contradicts the artist's optimism by default, not through analytical disagreement.

"Collinearity must stay bounded" — fails. The factor space is too small and factors are too similar. Collinearity is effectively 1.0 between FE and MD, and near-1.0 between AD and MD.

SET D — 9 Factors
(a) Mispricing

Unplanned Phone Call — undervalued. The call is penalized by F1 (Temporal Compression), F3 (Intermediation Density), F6 (Coordination Formalization), and F4 (Uncertainty Suppression). The only positive factor is F7 (Friction Valuation), which rewards its inconvenience. But the set has no factor for spontaneous human connection as a positive good; the call is priced as a bundle of costs with a small premium for friction. It cannot capture the possibility that people value the call despite its costs, not because of them.

Solitude — mispriced. F1 (Temporal Compression) is neutral, F4 (Uncertainty Suppression) is ambiguous, F5 (Physical Carrier Displacement) is neutral. The only clearly negative factor is F3 (Intermediation Density), which doesn't apply. Solitude is not well-exposed to any factor, making its price determined by noise and security-level fundamentals. It is effectively unmodeled.

Live Performance — overvalued. F2 (Human Act Substitution) penalizes it slightly (some substitution), F5 penalizes it (physical carrier displacement), but F8 (Scarcity Revaluation) rewards it massively as prevalence declines. The set conflates scarcity-driven price increases with fundamental value. Live Performance is priced as if its decline is a reason to buy it, which may be true in a market but is not a sustainable valuation model.

(b) Unattributable events

Event: A pandemic leads to widespread remote work; after the pandemic, some workers choose to return to offices despite having the option to remain remote, citing a need for "accidental encounters."

Where it lands: F4 (Uncertainty Suppression) — but this is about reintroducing uncertainty, not suppressing it. F3 (Intermediation Density) — but this is about removing intermediation, not increasing it. F6 (Coordination Formalization) — but this is about spontaneous encounters, not formalized ones. The event is a reversal of the set's directional assumptions; no factor captures a voluntary return to uncertainty and spontaneity.

Event: A new film camera is released that uses AI to suggest compositions to the photographer, while still using film.

Where it lands: F2 (Human Act Substitution) — but the substitution is augmentation, not replacement. F4 (Uncertainty Suppression) — but the AI reduces uncertainty in composition while film retains uncertainty in development. F9 (Social Legibility) — ambiguous. The set cannot decide whether this is substitution (bad), suppression (bad), or legibility (ambiguous). The move would split across factors.

(c) Identification failure at eleven securities

F1 (Temporal Compression), F4 (Uncertainty Suppression), and F6 (Coordination Formalization) collapse. Across these eleven securities, the three factors are perfectly correlated. Every practice affected by time compression is also affected by uncertainty suppression and coordination formalization, in the same direction. The three are conceptually distinct but empirically identical on this universe.

F2 (Human Act Substitution) and F5 (Physical Carrier Displacement) collapse. Substitution and dematerialization move together. A security whose human performance is replaced is also dematerialized; a security that is dematerialized is also agency-displaced. No security separates them.

F7 (Friction Valuation) and F8 (Scarcity Revaluation) are near-collapsed. Both are cyclical valuation factors that reward decline and penalize abundance. They move together on most securities. They separate only on Handmade Object (scarcity is high, friction is also high) and Physical Media (scarcity is high, friction is moderate) — two securities of separation, insufficient for a nine-factor model.

(d) Double counting

The decline of a practice enters three times. A decline in Film Photography is captured by F1 (time compression — digital is faster), F2 (human substitution — digital replaces), F4 (uncertainty suppression — digital predicts), and F5 (physical carrier displacement — digital is dematerialized). Four factors capture the same decline. Each factor is directionally distinct conceptually, but in practice they all move together, creating quadruple-counting of the same real-world trend.

Scarcity enters twice. F8 (Scarcity Revaluation) is explicitly about scarcity. F7 (Friction Valuation) also captures scarcity indirectly — if something is scarce, it requires more effort to obtain, so it is also friction-valued. The same process enters twice.

(e) What this set can never say

That a practice might be valuable because it is abundant. Every factor in SET D treats decline, scarcity, and friction as positive (with the exception of F7 which makes friction cyclical rather than unambiguously good). The set has no language for "this practice is valuable because many people do it, because it is accessible, because it is common." Serendipitous Discovery loses value as it becomes rarer, but the set cannot express that it might also gain value as it becomes more common — that discovery is better when there are more discoverers.

(f) Falsification risk

"Collinearity must stay bounded" — fails. The collapse of F1/F4/F6 and F2/F5 means the factor space is underidentified. The model can produce exact attribution, but the attributions are arbitrary — any linear combination of collapsed factors produces the same price. This is a structural failure, not a cyclical one.

"Film photography must be able to revive" — at risk. Film is penalized by F1, F2, F4, and F5. It is rewarded by F8 (scarcity) and potentially F7 (friction) and F9 (social legibility). A revival requires the cyclical valuation factors to dominate the structural decline factors. Possible but precarious.

"Attribution must sum exactly" — passes.

That a practice's value might be independent of both structural conditions and social status. Every factor in SET E ties value to something external: structural displacement, economic scarcity, social interpretation, market positioning. If a practice is valuable simply because it is valuable, SET E cannot express that.

"Film photography must be able to revive" — passes, but with constraints. Revival would require E1, E2, and E3 to outweigh S1-S4 and E6. Possible but requires strong cyclical forces.

Section 2 — Shared versus Specific Failure
Failures that appear in every set
Shared Failure 1: Directional bias toward structural decline

Every set is structurally biased toward the conclusion that all eleven securities are declining in value. This is not a feature of any particular set; it is a feature of how the problem has been framed. Every set treats the digital, the fast, the mediated, and the automated as the baseline, and treats the analog, the slow, the spontaneous, and the human as deviations from that baseline. No set is structurally neutral; all are structurally pessimistic.

What this means: The model will always tend to price these securities as declining, absent strong cyclical or status-driven reversals. This is a property of the problem as framed, not of any individual set. No choice of set will fix this.

Shared Failure 2: Inability to express positive value of the practices themselves

All six sets define the value of these practices in terms of what they lack (digital, frictionless, fast) or what they resist. None can express that a practice might be valuable intrinsically — because of what it is, not because of what it is not. The domain of "intrinsic value" is structurally excluded from every factor set.

What this means: The model can only ever price these securities as survivors of decline, never as flourishing independent of external pressures. This is a limitation of the factor approach itself, not of any particular factor selection.

Shared Failure 3: Collinearity among secular factors

In every set with more than five factors, the secular factors are collinear. Time compression, human substitution, mediation, dematerialization, and uncertainty reduction all move together across these eleven securities. This is not because the factors are badly chosen; it is because the securities themselves are all exposed to the same set of structural changes. The universe is too small to separate these effects empirically.

What this means: Any set with more than about five factors will be underidentified. The exact number varies, but the fundamental problem is structural: eleven securities cannot support more than about five independent factors on empirical grounds alone. This is a property of the security universe, not of the factor sets.

Shared Failure 4: Difficulty attributing cultural reversals

All six sets struggle to attribute events that represent a cultural reversal — a voluntary return to analog, a preference for slow over fast, a rejection of convenience. Such events require factors to move in the opposite direction of their structural trend, which is possible but mechanically difficult and conceptually awkward. The sets are designed to track decline; tracking revival requires factors to behave in ways they were not designed for.

What this means: The model can produce a revival, but it must do so through cyclical factors (status, friction premium, authenticity cycles) rather than through structural revaluation. Revival is always precarious and dependent on mean-reverting signals. This is a property of the model's architecture, not of any particular set.

Shared Failure 5: Silence on well-being

None of the sets can express that a practice might be valuable because it makes people happier, healthier, or more connected. Value is always expressed through social status (legibility, signaling, authenticity) or through scarcity (friction premium, revaluation). The intrinsic human value of these practices is structurally absent.

What this means: If a practice becomes more valuable to people but less scarce or less statusful, the model cannot capture that. This is a limitation of the financial framing itself, not of any particular factor set.

Failures specific to particular sets
SET A — Specific failure: Two missing dimensions (Ambient Time, Intrinsic Value)

SET A lacks factors for non-productive time use and for intrinsic value. It is the only set that fails on both of these dimensions simultaneously. Most other sets capture at least one of these dimensions partially; SET A captures neither.

SET B — Specific failure: Unpriced factors create blind spots

SET B is the only set that unprices factors it considers important (F4 Coordination Formalization, F9 Generalized Trust). This creates specific blind spots: Solitude and Unplanned Visit are particularly affected by these unpriced factors. The set is betting that these factors can be ignored without loss of explanatory power. This is a gamble, not a finding.

SET C — Specific failure: Severe underdimensioning

SET C is the only set with five factors, and it is the only set where all factors are at risk of collapse. The factor space is too small to capture the domain's complexity. This is a specific failure of factor count, not of factor choice.

SET D — Specific failure: Scarcity as a universal positive

SET D is the only set that treats scarcity (F8 Scarcity Revaluation) as an unambiguous positive, independent of the practice's actual value. This creates systematic overvaluation of declining practices. The set is particularly vulnerable to mispricing Live Performance and Physical Media.

SET E — Specific failure: Intrinsic value as a function of everything except the practice

SET E is the only set that separates structural, experiential, and reflexive layers conceptually, but does not specify how they interact. The set is the most sophisticated in its architecture but the least specified in its dynamics. This creates a specific failure of model completeness: the set has a structure but not a process.

SET F — Specific failure: Structural pessimism with no affordances

SET F is the only set that treats technology entirely as displacement and extraction, with no positive affordances. This creates a specific bias: any technological event is necessarily negative. This is a failure of the set's ontology, not just its factor selection.

Section 3 — Failure Cost under This Work's Purpose

LONGING is an artwork, not a fund. The failure costs must be assessed in artistic, not financial, terms.

Failure Class: Directional bias toward structural decline

Statistical severity: High. The model will systematically undervalue the securities.

Artistic severity: Moderate to low. The artwork is explicitly about tension between calculation and the incalculable. A model that is systematically pessimistic about human practices may be artistically coherent — it creates dramatic tension. The audience expects the model to be wrong about the human. If the model were perfectly fair, the contrast would be less sharp.

Judgment: This failure is artistically tolerable. It is not a bug; it is the premise.

Failure Class: Inability to express intrinsic value

Statistical severity: High. The model is missing an entire source of value.

Artistic severity: High. The artwork is about practices whose value may be intrinsic, not instrumental. If the model cannot even express the possibility of intrinsic value, it is not just wrong — it is deaf to the subject matter. This is not a statistical failure; it is a conceptual failure. The artwork's central tension requires the model to struggle with intrinsic value; if the model cannot represent it, the struggle is empty.

Judgment: This failure is artistically severe. It undermines the artwork's purpose.

Failure Class: Collinearity among secular factors

Statistical severity: High. The model is underidentified.

Artistic severity: Moderate. The artwork publishes exact attribution ledgers. If those ledgers are arbitrary (because factors are collinear), the attribution is performative rather than meaningful. This may be artistically interesting — the artwork's surface of exactitude is revealed as empty — but it also risks being merely misleading rather than illuminating.

Judgment: Moderately severe. Exact attribution is part of the artwork's aesthetic. Collinearity undermines that aesthetic. If the audience understands the collinearity, it is artistically fruitful; if it does not, the artwork is deceptive.

Failure Class: Difficulty attributing cultural reversals

Statistical severity: High. The model is built for decline, not revival.

Artistic severity: Low. The artwork's bias toward the human means it expects revival. A model that struggles to attribute revival is not a failure; it is the resistance the artwork needs. The difficulty of revival in the model creates the drama.

Judgment: This failure is artistically tolerable. It is part of the work's structure.

Failure Class: Silence on well-being

Statistical severity: High. The model is missing a fundamental driver.

Artistic severity: High. The practices in the universe are human practices. Their value to humans — their effect on well-being — is central to their meaning. If the model cannot express well-being, it is not engaging with the subject. This is a more severe failure than mispricing.

Judgment: This failure is artistically severe. It reduces the practices to objects of status, scarcity, and decline, stripping them of their human meaning.

Statistical severity does not imply artistic severity

A failure being statistically severe — collinearity, underidentification, mispricing — may be artistically neutral or even beneficial. The artwork is not a fund; it does not need to be right. It needs to be interesting, rigorous, and faithful to its tension.

A failure being artistically severe — missing intrinsic value, silencing well-being — is fatal regardless of statistical severity. The artwork becomes a technical exercise rather than a meditation on the human.

Section 4 — Minimal Repair
SET A

Smallest change: Add a factor for Ambient Value — value that does not depend on resistance, substitution, or signaling. Definition: "The degree to which a practice is valued for its own character, independent of its relationship to digital alternatives, social status, or market conditions."

What it costs: The set expands to nine factors. The new factor is structurally similar to "baseline" value and may itself be collinear with security-level fundamentals. It complicates attribution because any unmodeled value can now be attributed to Ambient Value rather than to the security's fundamentals. The factor is effectively a residual, which violates the principle of no unexplained remainder.

What it breaks: The sharpness of the attribution ledger. With Ambient Value, any positive move that cannot be explained by the other seven factors goes here. The factor becomes a catch-all, reducing the model's diagnostic power.

SET B

Smallest change: Price F4 (Coordination Formalization) and F9 (Generalized Trust) immediately, removing the promotion condition. Definition: run them as zero-supply factors with coefficients estimated from cross-sectional variation.

What it costs: The set becomes a full twelve-factor model. Attribution becomes more granular but also more collinear. F4 and F9 are likely collinear with existing factors (F6 Attention Slack, F10 Commodification), creating additional identification problems. The set's current self-limiting discipline (unpriced factors) is lost.

What it breaks: The set's execution rule was a deliberate constraint to limit identification failure. Removing it exposes the full collinearity of the twelve-factor space. The model becomes more expressive but less stable.

SET C

Smallest change: Split SR (Social Revaluation) into two factors: Social Status (signaling/performance) and Cultural Resonance (intrinsic cultural value independent of status). This adds a dimension that can capture positive valuation not driven by status.

What it costs: The set expands to six factors. The new factor is likely collinear with the remaining four, as Cultural Resonance may move in the same direction as Social Status (both tend to reward authentic practices) and against the structural factors. The factor space remains underdimensioned.

What it breaks: The parsimony of the five-factor set. The set is currently the most compact; expanding it sacrifices the simplicity that was its virtue.

SET D

Smallest change: Replace F8 (Scarcity Revaluation) with Positive Valuation — value that increases with practice quality, not with scarcity. Definition: "The degree to which a practice is valued for its intrinsic character, independent of its prevalence."

What it costs: The set loses its ability to capture scarcity effects. Scarcity is a real driver of value in markets; removing it may create mispricing in the opposite direction (undervaluing declining practices).

What it breaks: The set's mechanism for revival. Currently, revival is driven by scarcity (F8) and friction (F7). Replacing F8 removes one of the two paths to revival, making the set more structurally pessimistic.

SET E

Smallest change: Add a cross-layer interaction rule specifying how R1 (Positioning/Crowding) feeds back into the valuation layer. Definition: "Positioning affects the price through the valuation factors, not independently."

What it costs: The set becomes more specified but also more complex. The interaction rule creates a dynamic feedback loop that must be calibrated. The exact functional form is not specified, creating new degrees of freedom.

What it breaks: The conceptual separation of layers. The set currently has a clean structural-experiential-reflexive architecture. Adding cross-layer interactions blurs the boundaries and makes the set harder to interpret.

SET F

Smallest change: Add an affordance factor: Technological Affordance — value created by technology enabling new forms of human contact, creation, or expression that were previously impossible. Definition: "The degree to which a practice is enabled, enhanced, or created by technological systems."

What it costs: The set expands to eleven factors. The new factor is likely collinear with existing factors (P5 Mediation & Extraction), as many affordances are also mediations. The set would need to distinguish affordance from extraction, which is difficult to do empirically.

What it breaks: The set's structural pessimism. Adding affordance introduces a positive technological dimension that counteracts the structural pressures. The set becomes more balanced but less consistent in its worldview.

Section 5 — What Would Settle It
Test 1: Secular reversal simulation

Run a simulation in which a major secular reversal occurs — a voluntary return to analog practices, widespread rejection of convenience, a social movement toward slowness. Simulate this as a shock to one or more factors (depending on the set) and observe:

Which set's price path is most plausible?

Which set produces the most coherent attribution of the reversal?

Which set fails catastrophically (prices go negative, attribution breaks)?

What it tests: The set's ability to handle the artwork's central dramatic tension.

Test 2: Security-level cross-validation

For each set, estimate the factor model on a subset of securities (say, eight of eleven) and test how well it predicts the prices of the remaining three. Do this with leave-one-out cross-validation across all subsets.

Which set has the lowest out-of-sample prediction error?

Which set's factor loadings are stable across subsets?

What it tests: The set's empirical identification, free from in-sample overfitting.

Test 3: Collinearity decomposition

For each set, compute the condition number of the factor loading matrix. This is a standard measure of collinearity.

Which set has the lowest condition number (least collinearity)?

Which set has the highest (most collinearity)?

What it tests: The set's statistical identifiability.

Test 4: Attribution audit

Present human judges with a set of simulated events and the attribution ledgers produced by each set. Ask the judges to rate the plausibility of the attribution:

Does the event "map onto" the factors in a way that makes sense?

Is the attribution insightful, or merely technical?

What it tests: The set's conceptual coherence, not just its statistical properties.

Test 5: Stress test — contradictory movements

Simulate an event in which one factor rises and another falls (e.g., time compression increases while attention scarcity decreases). Observe which set produces the most plausible price path.

Which set can handle contradictory movements without breaking?

Which set's attribution remains legible?

What it tests: The set's dynamic stability.

Test 6: Revival capacity test

Run a simulation in which Film Photography is explicitly shocked positively (e.g., a cultural revival, new technology, status shift). Observe:

Which set produces a revival without heroic assumptions?

Which set's revival is the most stable (not dependent on a single factor)?

Which set's revival is the most coherently attributed?

What it tests: The set's ability to fulfill the artwork's requirement that Film Photography must be capable of a genuine revival.

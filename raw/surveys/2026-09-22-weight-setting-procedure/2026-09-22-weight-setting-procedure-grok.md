# LONGING RESEARCH — Setting a Security's Execution and Judgment Weights

This is a procedure for assigning a fixed pair *(execution share, judgment share)* that sums to one. It does not set weights for any security. Every number below is *illustrative*. What varies by era — exposure to execution restored, exposure to judgment substituted — is out of scope.

Training note. LETTER is described from ordinary knowledge of handwritten correspondence. No claim here depends on a measurement of real practices after a cut-off. The three hard cases are taken as given.

---

## Section 1 — The unit of classification

The unit that is labelled execution or judgment is a **step of the canonical occasion**.

Not the whole practice: one label would hide the mix the weights exist to record. Not a historical occasion: weights are fixed and era-invariant. Not a bare decision point: that would drop the doing the execution share is meant to name.

A **canonical occasion** is one complete performance of the practice as the published definition describes it. For LETTER: one message personally composed, physically handwritten, intended for a particular person, and released to that person through a delivery route.

A **step** is a named, bounded stretch of that occasion that meets all four tests:

1. **Nameability.** Someone who knows the practice can point to it without a private vocabulary.
2. **Omitability-in-principle.** Performing or skipping it is recognizable as adding or dropping a part of the occasion. The result is still a letter, or it is something the definition would refuse to list.
3. **Single primary question.** The stretch is governed by one question, not both at once: *what is selected?* or *how is an already-selected content realized in body or material?* Where both are live and cannot be sequenced, the stretch is listed once and marked mixed (Section 2).
4. **Stop rule.** A further cut would either produce a fragment no ordinary description names, or would split a single set of live options into the options themselves. Options are the content of a step, not further steps.

**Finite-list test.** Two classifiers, working only from the frozen definition sentence and a one-page practice note, list steps independently. The lists can be aligned by name. Unmatched steps are fewer than one in five on either list. Unmatched steps are then admitted, merged, or dropped in a written reconcile. That reconcile is the official inventory. If the lists cannot be aligned to that standard, the definition is not tight enough to carry weights.

### Decomposition of LETTER

Definition used here (fixed for the illustration): *a personally composed, physically handwritten message intended for a particular person and released to that person through a delivery route.*

| ID | Step | What it is |
|----|------|------------|
| L1 | Occasioning | Forming the intention that a letter, now, is the act. |
| L2 | Addressing | Holding a particular person as the intended reader. |
| L3 | Composing | Selecting the words, their order, and what is withheld, before or apart from the hand's motion. |
| L4 | Furnishing | Selecting and preparing the surface and the instrument. |
| L5 | Inscribing | Physically handwriting already-chosen words onto the surface. |
| L6 | Revising-in-ink | Alterations that remain part of the sent object. |
| L7 | Binding | Valediction and signature; claiming the text as the writer's. |
| L8 | Enclosing | Folding, inserting, sealing. |
| L9 | Directing | Marking the packet so a route can find the person. |
| L10 | Releasing | Placing the packet into a route the writer does not thereafter control. |

L5 and L6 are listed separately because the definition names physical handwriting as its own clause, and because L6 is the mixed case inside LETTER. Merging L3 with L6 is allowed only if the inventory record says so. This table shows the *form* of a decomposition. It is not a signed official list.

## Section 2 — The sorting rule

The record's candidate — whether the step handed over contained more than one live option — is adopted as the core and restated. Weights classify the intact practice. Handover belongs to exposure, which is not this procedure.

### The live-option test

At the start of step S, does the practitioner face more than one **live option**?

A live option is an alternative that meets all three:

- (a) it remains inside the practice (taking it still yields a letter, not another security);
- (b) it is available to the practitioner without special leave;
- (c) a competent observer would count the result as a **different instance** of the same security — a different letter — and not merely a differently executed copy of the same letter.

Then:

- If yes → **judgment**.
- If no — S only realizes options already closed → **execution**.
- If motor performance and option-set cannot be sequenced (the hand invents the next clause as it writes) → **mixed**.

**Manner is not a live option.** A neater hand, another paper, another timbre does not satisfy (c). Those are different executions of the same letter. Skill acquired before the occasion, including a voice learned from another person, is not a live option inside the occasion.

**Restoration is not a live option.** A device that returns a capacity the person already used to close options — a decoder that voices a sentence already chosen — does not open options. It restores a realization channel. The step remains execution.

**Closing someone else's options is judgment even when it looks like doing.** A system that turns a short instruction into the words the other person will receive is closing live options of tone, distance, and idiom. That step is judgment.

**A changed information set is not a reclassification.** If the person still performs the step and still faces live options, the label does not change because the options arrived in another order or with a gloss attached.

### Mixed steps

A mixed step is split. It is not left as a third category in the pair.

First try to sequence it: the stretch that selects is judgment; the stretch that realizes a closed selection is execution. If they cannot be sequenced, assign a recorded fraction in quarters (¼ / ½ / ¾). The default is ½. Any other quarter needs one written sentence of reason. Open-ended decimals are not used. Classifiers set the fraction in the same pass as the label; the user signs it in Section 4.

### The three hard cases

**Case A — execution with a restoring side.** Voicing a sentence the person chose. The unit is the voicing. At its start the sentence is already selected. No live option under (c). **Execution.** A speech decoder for ALS is arrival of a realization channel, not a change of label. Reading a text aloud in a voice learned from another person is the same: the text is selected; the voice is prior skill. **Execution.**

**Case B — doing that hands over deliberation.** Sending *how are you* and letting a system produce the utterance that will be received. At the start of that production many live options remain. The system closes them. **Judgment.** Had the person composed the exact received sentence and the system only realized that sentence in another script or another mouth, the realizing stretch would be execution. The given case is not that.

**Case C — judgment kept but narrowed.** A system's interpretation is read before the original; the person's decision changes; no step is handed over. No unit of the practice has changed hands. The person still faces live options. **The pair does not move.** If the case is measured at all, it is measured as exposure.

### What the rule cannot decide

- A practice with no stable canonical occasion (nothing listable).
- A step whose options are socially forced to one respectable choice. Whether “use the honorific” is a live option or a manner depends on whether a competent observer in that market would count the other choice as a different letter or as a broken letter. The rule names this **ambiguous** and sends it to the fallback.
- Whether two listings are one security or two. That is a definition question.

**Fallback.** An ambiguous step is marked *undecided*. The pair is computed under both labels. Both figures, and the interval they span, go in front of the user. The pair is not averaged in silence.

## Section 3 — The counting rule

Classified steps become a pair by **definitional load**. **Equal count** is printed beside it as a check.

### Definitional load

Each step receives an integer load in {1, 2, 3}, read only from the frozen definition sentence, before anyone looks at a generated price path.

- **3** — the step is named by, or is the direct object of, a clause in the definition.
- **2** — the step is necessary for those clauses to be possible, but is not itself named.
- **1** — the step is customary support.

*Illustrative* loads for LETTER against the definition in Section 1:

| ID | Step | *Illustrative* load | Why (*illustrative*) |
|----|------|---------------------|----------------------|
| L1 | Occasioning | 2 | Makes the act an intended letter. Not named. |
| L2 | Addressing | 3 | “intended for a particular person” |
| L3 | Composing | 3 | “personally composed” |
| L4 | Furnishing | 1 | Support for handwriting. |
| L5 | Inscribing | 3 | “physically handwritten” |
| L6 | Revising-in-ink | 2 | Part of the composed object that is sent. Not named. |
| L7 | Binding | 2 | Makes “personally” claimable. Not named. |
| L8 | Enclosing | 1 | Support for the route. |
| L9 | Directing | 2 | Instrument of the route. Not named. |
| L10 | Releasing | 3 | “released … through a delivery route” |

*Illustrative* arithmetic, only to show the form. Suppose L1, L2, L3, L6, L7 are judgment and L4, L5, L8, L9, L10 are execution:

- Judgment load = 2+3+3+2+2 = 12
- Execution load = 1+3+1+2+3 = 10
- Total = 22
- *Illustrative* pair: execution 10/22 ≈ 0.45, judgment 12/22 ≈ 0.55

Those figures are not a proposal for LETTER. A mixed L6 at ½ would split its load of 2.

**Execution share** = (loads of execution steps + execution fraction of mixed loads) / (sum of all loads).  
**Judgment share** = 1 − execution share.  
Report each share to two decimal places.

### What the weighting assumes and what it distorts

It assumes that the definition sentence is the identity of the security, and that a named clause should move the pair more than a supporting step. That is the same assumption the listing itself makes.

It distorts toward whatever the house chose to name. A padded definition overweights the padded clauses. Mitigation is mechanical: definitions stay short, frozen, and dated *before* classification. Adding a clause later is condition (a), not a quiet re-weighting.

**Equal count** (each listed step weight 1, mixed steps split as in Section 2) is computed on the same inventory and printed next to the load pair. It assumes that surviving the finite-list test already made the steps comparable. It distorts by treating Addressing as equal to Enclosing.

**Stop rule for the two pairs.** If the load pair and the equal-count pair differ by more than 0.10 on a share, the inventory or the definition is wrong. Classification stops until one of them is rewritten. The two pairs are not averaged.

Time-weighting is rejected. Inscribing lasts longer than Addressing and would pull the pair toward execution for a reason that has nothing to do with what the practice stands for.

Failure-frequency weighting is rejected until there is an era-invariant study of where the practice breaks. A study that used post-arrival tools would smuggle substitution into the weights.

Consequence-for-the-price-path weighting is rejected by the brief.

### Tolerance

Two independent teams, given the same frozen definition and the same official inventory, applying Sections 2–3 without consulting one another, must differ by at most **0.05** on each share. A run that misses that bound is not rounded in. It is an unfinished classification.

## Section 4 — Who sets it, and how disagreement is resolved

The user makes the final call. What is put in front of them is a **classification packet**, not a bare pair:

1. The frozen definition sentence and its date.
2. The official inventory, with the two source lists and the reconcile note.
3. For each step: label (E / J / mixed with fraction / undecided), the one-sentence live-option reason, and the definitional load.
4. The load pair, the equal-count pair, and the gap between them.
5. Any undecided step shown as an interval: the pair if the step is E, the pair if it is J.
6. Whether the 0.05 tolerance was met across the independent runs.

Three classifiers work first, independently, then meet once on the inventory and once on the labels. They may not see generated prices.

**Disagreement on one step's label.** Each side writes at most one page against the live-option test — which of (a), (b), (c) the other side fails. One reply each. If the label is then shared, it enters the packet as settled. If not, the step is *undecided* and the interval goes to the user. The user may pick a label, accept a mixed fraction, or send that step back for a finer cut. The user may not pick a pair that does not correspond to some labelling of the inventory.

**Disagreement on load.** The only evidence allowed is the wording of the frozen definition. If two readers cannot agree whether a clause names the step, the definition is tightened before weights are signed. Tightening a listed security's definition is condition (a).

The pair is not in force until the user signs the packet. Signature covers inventory, labels, loads, and pair together.

## Section 5 — Cross-market consistency

The ordinary procedure yields **one pair for all three markets**. Weights are part of the definition, not of local custom. The three markets list the same security only if they list the same practice.

**Detection of the disagreement condition (b) names.** Each market desk runs Sections 1–3 independently on the same frozen definition, with classifiers fluent in that market's ordinary description of the practice. Each desk files a packet. If any two desks differ by more than 0.05 on a share, a consistency file is opened.

The file compares inventories first, labels second, loads third.

- Inventories differ: the common definition does not yet describe one practice. Tighten the common definition so the extra or missing step is named for all three (condition (a)), or split the listing and name the variant. Do not issue three pairs under one name.
- Inventories match and labels differ: the live-option test is being read differently. That is a Section 4 disagreement. It is not yet condition (b).
- Condition (b) is met only when, after that resolve, the signed pairs still differ by more than 0.05. Section 6 then starts.

Market manners — honorifics, season-words, paper, typed-versus-handwritten norms — enter the weights only if the frozen definition names them. Otherwise they are manner, and manner is not a live option.

## Section 6 — The revision procedure

Weights move only under (a) or (b). Fit to the generated record is not a ground and is not discussed in the revision file.

**Who may initiate.** The user; any market desk; the consistency clerk who watches the three packets.

**What the revision record contains.**

- Security identifier and the pair now in force.
- The signed packet that produced that pair.
- Which condition is invoked.
- The evidence that satisfies that condition, attached, not paraphrased.
- The proposed new packet and new pair.
- Effective date.
- A sentence that published readings dated before the effective date stand.

**Evidence for (a).** A dated amendment to the published definition that adds or removes a named step, plus one paragraph stating that the practice itself lost or gained that step — not that a tool now performs it. “People still compose, but a system now composes” is exposure. “The listed practice no longer includes composing” is (a), and is a different security in all but name.

**Evidence for (b).** The three desk packets, the inventory diff, the Section 4 resolve note, and a finding that the remaining gap is larger than 0.05 and is not a misapplication of Sections 2–3.

**Published readings under the old pair.** They stand. The new pair applies only to readings dated on or after the effective date. A restatement series may be computed for study and marked as restatement. It is not substituted into the published record. Rewriting the thirty-year path under a new pair would be tuning by another door.

## Section 7 — Failure modes

Ranked by how hard each is to detect after the pair is in force.

1. **The definition is written to fit a desired pair.** Loads then look disciplined and are not. Hardest to see later: the paper trail is internally consistent. Mitigation: date-stamp and freeze the definition before any label or load is assigned; refuse a definition change that arrives in the same file as the first pair.
2. **A shared coarse inventory hides judgment inside one step named “write” or “send.”** Every later desk reproduces the error. Hard unless someone is asked to decompose LETTER from the definition with no inventory in hand.
3. **Composition is subdivided down to the word or the stroke.** Judgment share climbs toward 1 and the climb looks rigorous. Hard once the Section 1 stop rule has been ignored, because each local cut will pass the live-option test. Mitigation: the stop rule is part of the signed packet; a list longer than a page for a practice as short as LETTER is presumptively over-cut.
4. **Restoration (Case A) is treated as a new practice rather than as arrival on an old step.** Medium. Detectable if the revision file must say whether a step was added or only a channel restored.
5. **Case C is absorbed into the judgment share.** Medium. Detectable if every proposed weight change must name the step that changed hands.
6. **Manner and skill are scored as live options** (hand style, paper, acquired voice). Medium. Detectable from the one-sentence reasons, if those reasons are actually written.
7. **Market manners are encoded as definitional steps**, producing a false (b) or three pairs for one practice. Medium. Detectable from the inventory diff.
8. **Contested steps are averaged in silence.** Easier if the Section 4 packet is used; invisible if only the pair is stored.
9. **Time, failure-frequency, or the price path is used as a counting weight under another name.** The last of these is the forbidden mode. Easy if named; hard if the counting rule in the file is not the counting rule that was used.

The pair that survives these modes will still be a judgment. The claim of the procedure is narrower: another house, given the same definition and this document, should come within 0.05 of the same pair, and should be able to say which step produced any remainder.

## Objections

The live-option test uses “a different instance of the same security” as its identity test, and the security's identity is the definition sentence that also feeds the loads. That is circular in principle. The circle is accepted and then pinned: the definition is frozen first; identity for test (c) is read only off that sentence; any later wish to change what counts as a different letter must amend the sentence under condition (a) rather than reinterpret the test. If that pin is refused, the sorting rule has no external point to stand on, and weights cannot be made repeatable within a stated tolerance.

# DEC-001 — The work is named LONGING RESEARCH

> **Current name: LONGING RESEARCH** (2026-09-15). The one-word title recorded below was the decision from 2026-09-04 to 2026-09-15 and is preserved as history. Read the [evolution note](#evolution--the-title-takes-the-suffix-2026-09-15) first; the sections between here and it describe the superseded state.

## Decision — superseded 2026-09-15

The work was called **LONGING**, in capitals, with no suffix. The user stated it directly: "LONGING으로 가되" ("let's go with LONGING"). «사라져버린 낭만을 찾아서» is retained only as a working title for the theme.

## Rationale

- The word already means yearning, and contains **LONG**, the market position the work is built on. Read one way it is an emotion; read another it is a state — *LONG·ING*, being long on something. A third reading is prospective: what do we want to keep existing?
- The discovery is delayed. Before the viewer understands the work the name looks like an ordinary firm; afterward the name turns out to have been the structure.
- It extends cleanly into an institutional vocabulary: LONGING Terminal, LONGING Markets, LONGING Research, LONGING News, LONGING Data, LONGING Archive, LONGING Index.

## No descriptive suffix — superseded 2026-09-15

`LONGING TERMINAL` or `LONGING MARKETS` was rejected as the *work's* title, because naming the device in the title explains the work before the viewer enters it. The precedent is the sibling work, which is titled OTHER GOODS and not "OTHER GOODS STORE". The terminal, the markets, and the research desk exist as named entities *inside* the fiction; the work itself is one word. See [[system-grammar]].

## Known risk

`LONGING` alone reads as emotional, which works against the intended dry first impression. The mitigation is branding: no serif logotype, no hazy photography, no on-screen gloss of the word. The mark is used as a plain system logo, paired with deliberately clerical extensions (`LONGING PROFESSIONAL`, `LONGING RESEARCH`).

## Rejected and deferred alternatives

Candidates were judged against three criteria: it must pass as a real financial institution, it must carry a second meaning discovered later, and it must connect to the LONG / HOLD / SHORT structure.

| Candidate | Why not chosen | Status |
|---|---|---|
| CONSENSUS | Strong — names the idea that price is a temporary settlement between opposed judgments. Kept as a concept inside the work rather than as its title. | `rejected` as title |
| POSITION | Strong — puts the viewer's own judgment at the center ("Take a position."). Was the LLM's late preference; the user chose LONGING. | `rejected` as title |
| HOLD | Reads as an argument ("some things are worth holding"), which conflicts with giving LONG and SHORT equal standing. | `rejected` |
| RESIDUAL | Fits residual value, but has no link to the LONG/HOLD/SHORT structure. | `rejected` |
| UNPRICED | Slogan nearly writes itself ("We price what the market cannot."), but the institution would already be taking a philosophical position. | `rejected` |
| COMMON / ORDINARY | Quiet and human, but weak financial camouflage. | `rejected` |
| AFTERMARKET | Existing commercial meaning too strong; trademark and search collisions. | `rejected` |
| LONG ONLY | Real and common financial phrase; poor as a distinctive name. | `rejected` |
| ROMANCE INDEX / Romantic Exchange | Names the subject outright and explains the work too early. Also collides with prior art — see [[prior-art]]. | `rejected` |

A planned round of trademark, domain, and existing-artwork collision research on the shortlist was never carried out before the user settled on LONGING. That check is still outstanding.

## Evolution — the title takes the suffix (2026-09-15)

**The work is named LONGING RESEARCH.** The user directed the change in one line:

> LONGING RESEARCH로 개명 처리해줘.

### Why

The reason is not in the rename turn itself. It is in the earlier conversation the same day, where the user stated the series' title format while naming the two new instruments:

> 지금 각 작품별로 이름이 두 단어 씩이야. OTHER GOODS, LONGING RESEARCH 와 같이 말이야.

So the governing rule is now **two words per work**, and the user was already using *LONGING RESEARCH* as the work's name while stating it. The assistant flagged the clash with this decision and held it as an unresolved contradiction for one turn rather than acting on it; the rename turn resolved it.

### What this reverses

This directly reverses the *No descriptive suffix* section above, including its precedent. That section rejected `LONGING TERMINAL` and `LONGING MARKETS` on the grounds that naming the device in the title explains the work before the viewer enters it, and cited the sibling work as the precedent — titled OTHER GOODS, not "OTHER GOODS STORE".

The user's own stated rule now reads that same sibling the other way: OTHER GOODS is **two words**, and so is LONGING RESEARCH. Both readings of the precedent are on record. The user's is the operative one.

Two consequences of the reversal are worth keeping visible, because the original objection was not answered, only overruled:

- **The title now names the device.** `RESEARCH` tells the viewer this is a research house before they enter. The original argument against that stands as an argument; the user chose the format anyway.
- **The title absorbs one of its own in-fiction entities.** The *Rationale* section above lists `LONGING RESEARCH` as one of the clerical extensions the one-word name made available, alongside LONGING Terminal, Markets, News, Data, Archive, and Index. One of those extensions is now the work itself, which leaves the relationship between the work's title and the internally named desks undefined. See [[system-grammar]] and [[world-rules]].

### What does not change

- **The identifier stays `LN-001`.** Identifiers are assigned once and never reused or re-derived; the institutional registry records this explicitly.
- **The rejected candidates and their reasoning are unchanged.** CONSENSUS, POSITION, HOLD, and the rest were rejected against the same criteria, none of which the suffix affects.
- **The outstanding trademark, domain, and existing-work collision check is unchanged and now larger.** It was never carried out for `LONGING`, and `LONGING RESEARCH` has not been checked either.
- **The known risk and its mitigation still apply.** The word still reads as emotional; the suffix arguably reduces that, which was never the reason for the change and is not claimed as one here.
- **The LONG·ING double reading is untouched.** Nothing in the suffix disturbs it.

### Not done, and needing a decision

The Lab repository is still `longing-lab`. [DEC-001 — repository conventions](https://github.com/TENDER-SYSTEMS-LAB/tender-systems/blob/main/wiki/decisions/DEC-001-repository-conventions.md) in the institutional repository sets the convention `{project-slug}-lab`, which would now give `longing-research-lab`. Renaming a published GitHub repository is an outward-facing action affecting every existing link, including the cross-repository URLs written into THE RESERVE's conclusion decision, and was not performed. The same question applies to the social accounts recorded under `LONGING` in the institution's public-surfaces page.

# Romance Ontology — the first draft of the layered graph

The third stage of [[DEC-016-securities-chosen-top-down]]: analysis → abstraction → **ontology** → securities. The frame and form are the author's decision of 2026-10-05 ([[romance-analysis]] section 10): four layers, concepts placed by layer and tested against the five loss layers, a layered graph with named relations, only the balances and BLIND TRUST marked as quantities.

**Status.** This page is the assistant's first placement, `llm-proposed`. Every node cites the decision it comes from; where a node rests on a decision, the decision is the author's and the placement is the assistant's. The author reviewed it on 2026-10-05 and accepted the placement; the answers are in the next section.

## The author's review (2026-10-05)

From the assistant's questions, the author decided ([[SRC-2026-10-05-ontology-draft-decisions]]), `user-confirmed`:

| # | Question | Decision |
|---|---|---|
| 1 | Hostility | **An indicator beside the balances, not a quantity in the bond ledger.** The author added its use: a separate indicator that analysts consult in their analysis (`user-originated`). The form's rule stands: only the balances and BLIND TRUST are quantities. |
| 2 | Trust and belief | **Two separate balances.** Trust is held between two people; belief is the floor-side belief that people will gather again and someone will help, and confidence in the system is the changed form of this belief — the assistant's reading, accepted with the option. |
| 3 | Reflection | **A security priced through the practices it makes possible.** This keeps the confirmed rule that abstract conditions can be securities, and moves the weight problem of a state without steps to the practices behind it. |
| 4 | What a security is | **Practices are securities; balances and layers are read through indices over them** (reading C). |
| 5 | Placement | **No node is misplaced, missing or wrongly kept.** |

Still open, as the assistant reads it, `llm-proposed`: which practices are securities, and how many; how a state-security such as reflection is built from its practices; which indices read which balances and layers, which is now where the one market's index question sits; and how analysts use the hostility indicator.

## Node kinds

| Kind | What it is | Marked as a quantity |
|---|---|---|
| **Rule** | A test that decides whether something counts | no |
| **State** | A condition a person is in, without steps | no |
| **Practice** | Something a person does, with steps; carries attributes | no |
| **Event** | Something that happens to a bond or a balance | no |
| **Quantity** | Something the ledger counts | yes — balances and BLIND TRUST only |
| **Attribute** | A property carried by a practice or an event | no |

## Named relations

The relation names are the assistant's, not a closed list.

```
 Origin test ──licenses──▶ Issue          (a bond counts only with a human origin)
 Attention  ──is the principal of──▶ Issue
 Occasion   ──prompts──▶ Issue
 Gathering  ──hosts──▶ Issue              (bilateral, never collective)
 Issue      ──accumulates──▶ Balances
 Coupon / Forgiveness ──keep alive──▶ Balances   (stock does not shrink)
 Call / Write-down / Default ──reduce──▶ Balances
 Device ──hides──▶ effort ──▶ Deskilling ──▶ Offloading ──removes──▶ Occasion
 Substitution of judgment ──raises──▶ Call ──moves reliance to──▶ BLIND TRUST
 Restoration / arrival ──raises──▶ Issue
 Non-technological rise ──raises──▶ Issue   (its own channel, 2026-10-10)
 Trust event ──raises briefly──▶ Issue      Service retirement ──writes down──▶ BLIND TRUST
```

## The loss test

Each concept is kept only if it makes a difference between records in at least one loss layer — practice, capacity, occasion, balance, sense ([[SRC-2026-10-04-romance-study-loss]]). The assistant's reading:

| Concept | Loss layer where it makes a record difference | Result |
|---|---|---|
| Practice, issue, call, coupon | practice (volume), balance | kept |
| Occasion, gathering | occasion (issuance) | kept |
| Capacity to choose, device → deskilling → offloading | capacity, occasion | kept |
| Balances, hostility | balance | kept |
| BLIND TRUST and its events | balance (the other side of the ledger) | kept |
| Origin test | every layer, as the rule that decides what is counted | kept, as a rule |
| Reflection | none directly; seen only through the practices it enables | kept, as a security priced through those practices (2026-10-05) |
| Chosen friction, resonance, ritual rhythm | practice (as attributes changing volume and seasonality) | kept, as attributes |
| Attention as a gift | none by itself | ground |
| Unsettled debt and promise | none by itself; carried by issue and coupon | ground |
| Comfort designed without malice (Circe) | none by itself; the cause behind device and substitution | ground |
| Loss of the sense of loss | sense — shown only through differences between records | kept, as a reading across records, not a node |

## What a security can be in this graph

Three readings, `llm-proposed`. The author chose C on 2026-10-05.

| Reading | A security is | Consequence |
|---|---|---|
| A. Practice | An exchange-layer practice; its float is the BEARER BONDs issued through it | Closest to [[DEC-015-no-listing-and-a-stopped-price-stays]] and the weight procedure; states without steps are not securities |
| B. Balance | One of the balances (love, understanding, trust, belief) | Four securities at most; too few for a market of many names |
| C. Practice, with layers as indices | Securities are practices; balances and layers are read through indices over them | The one market's index question moves here; a state such as reflection is priced through the practices it enables |

## Questions for the author — answered 2026-10-05

Kept as asked; the answers are in the section above.

1. **Hostility as a quantity.** The 2026-10-04 decision made hostility a separate quantity; the 2026-10-05 form marks only balances and BLIND TRUST. Add hostility as a third quantity, or treat it as an indicator beside the balances?
2. **Trust and belief.** Two balances, or one with belief as its floor form?
3. **Reflection.** A node of the origin layer that is not itself counted, or a security priced through the practices it enables? This decides the earlier rule that abstract conditions can be securities.
4. **What a security is:** reading A, B or C above.
5. **Placement.** Is any node misplaced, missing or wrongly kept?

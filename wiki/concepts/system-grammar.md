# System Grammar

The rule that connects LONGING to OTHER GOODS and, potentially, to later works by the same artist. The user asked for the alignment explicitly: LONGING should follow the same broad grain as the work of the artist behind OTHER GOODS. This page records the grammar that was formulated in response — an internal design principle, not a public statement.

> **Human things, processed by systems that were never made for them.**

Take a completely familiar, completely normal contemporary system, keep it intact, and put into it the human material it was never built to handle.

| | OTHER GOODS | LONGING |
|---|---|---|
| Surface | E-commerce | Financial terminal |
| System | Product, inventory, price, purchase, delivery | Quote, index, research, position, consensus |
| Object | What cannot be owned | What cannot be agreed on |
| System's behavior | Treats it as merchandise | Values it as an asset |
| Human question | Can this be owned? | What is this worth? |
| Core contradiction | Unownable → Goods | Unquantifiable → Price |
| UI posture | A perfectly normal shop | A perfectly normal financial terminal |

The transform is the series' generative device, and it extends: a recruitment work would be *Unnecessary → Qualification*, an archive work *Unforgettable → Data*, a legal or administrative work *Intimate → Procedure*. The formats set aside in [[DEC-002-research-house-form]] are candidates for exactly this.

## The interface must not be the beautiful part

The stated principle carried over from OTHER GOODS: *the interface should be immediately understandable; the work should not be.*

What is striking in OTHER GOODS is not the shop UI — the UI is ordinary. What is striking is that `Add to Cart` sits beside *the four o'clock sunlight of 13 June*. LONGING must work identically: the financial UI is not the aesthetic object, it is merciless and normal, and the strangeness is that `SHORT · PT 14.20` sits beside *the summer of 2004, the time spent waiting for a reply*.

## The system never understands emotion

A rule set early and kept throughout. Whatever happens to the person, the system answers in its own register:

- Grief → `Your request has been processed successfully.`
- The end of love → `The contract has expired.`
- A memory fading → `The data retention period has ended.`
- Missing someone → `No search results.`

The indifference is the mechanism. Romance becomes visible precisely because the system cannot see it.

## Where the bias lives

The user asked for a faint tilt toward romance and floated making SHORT analysts read as machine-like or villainous, while asking whether that was too obvious. It was set aside as too legible — a machine-versus-human reading resolves the work instantly. See [[Q-003-calibrating-the-bias]].

The bias is placed in the structure instead, as asymmetries the viewer feels without being told:

- SHORT reports are more often correct; LONG reports are longer remembered.
- The SHORT analyst has the highest accuracy in the institution — and the more often he is right, the further the LONGING Index falls.
- LONG reports occasionally introduce variables that cannot be measured: `Intent`, `Memory Persistence`, `Human Residual Value`.
- The system displays all reports equally, yet the Archive holds a strangely disproportionate number of LONG reports on securities that no longer exist.
- Where the SHORT analyst correctly predicted a delisting, the page ends with a cold `Coverage Discontinued` — and below it, very small, one trace left by a past user.
- A LONG analyst's target prices are often wrong, and years later her sentences reappear as the work's own epigraphs.

The artist never says LONG is right. A viewer who stays long enough notices that the work is quietly sorry about the disappearing side.

## The inversion at the center

In a financial system, a falling price means a worthless asset. Here the opposite runs underneath: **as market value disappears, human value increases.** A security page shows a price collapsed to 17.42 and, scrolled further, disclosures like *17 March 2004, Dongjak-gu, Seoul — "I had no assurance a reply would come. I checked the mailbox every day anyway."*

The formulation the source conversation kept returning to:

> We did not lose romance. We began classifying what cannot be measured as unimportant.
